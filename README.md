# SIKKIM — Where the Mist Meets the Divine

A living digital museum and pilgrimage through the monasteries, heritage and culture of Sikkim. Every scroll reveals another chapter — monasteries wrapped in mist, prayer flags against blue skies, and a single golden roof glowing through the haze.

## Features

- **Cinematic entrance** — a scroll-driven gate opens onto the monastery chamber
- **Monastery atlas** — an interactive parchment map of Sikkim's sacred halls
- **Digital museum** — festivals, clothing, food, prayer wheels, architecture, paintings and more
- **Plan Your Journey** — curated itineraries for every kind of traveller
- **Things To Do** — activities across Sikkim with seasons, safety and nearby places
- **Explore Places** — famous landmarks and hidden gems with travel detail
- **Ask the Guide** — a floating monastic assistant answering visitor questions
- **Bilingual** — English and Hindi

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start the production server
- `npm run lint` — run ESLint

## Tech

Next.js (App Router), React 19, Tailwind CSS v4, Lenis smooth scrolling, TypeScript.
